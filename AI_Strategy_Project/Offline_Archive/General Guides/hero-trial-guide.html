Hero Trial Guide — Daily PvE Stages and Cross-Server Hero Trial

Events · 2026-04-26

What Is Hero Trial?

Hero Trial is a daily PvE event in Last War: Survival. Every day, one hero is featured, and you can complete that hero's trial stages for targeted hero shards, skill medals, hero EXP, and gems. It is one of the most consistent free reward sources in the game and one of the few ways to farm shards for specific UR heroes outside of Hot Deals and the Alliance Shop.

The Hero Trial Habit

Hero Trial runs every single day. Skipping it skips daily hero shards for free. The total reward across a month — usually 50-100 named hero shards plus gems and skill medals — is the difference between a hero hitting 5★ on schedule versus a month behind. Five minutes daily is all it takes.

How Hero Trial Works

Each day, one hero from the UR roster is featured. You can run that hero's trial stages multiple times per day to accumulate rewards.

Daily Structure

  • One featured hero per day — rotating through the UR hero pool
  • Multiple stages of escalating difficulty per hero (typically 5-7 stages)
  • Daily attempt limits — you can run each stage a fixed number of times per day
  • Rewards scale with difficulty — higher stages give more shards and better drops
  • Stage completion is permanent — once you clear a stage, you have permanent access to its rewards on future rotations

Hero Rotation Schedule

The featured hero typically follows a weekly rotation. Common patterns include:

DayCommon Featured Hero (varies by server)
MondayTank-class hero (Kimberly, Murphy, Williams, etc.)
TuesdayAircraft-class hero (DVA, Morrison, etc.)
WednesdayMissile-class hero (Tesla, Fiona, etc.)
ThursdayTank rotation 2
FridayAircraft rotation 2
SaturdayMissile rotation 2
SundayOften a flexible / catch-up day

The exact rotation varies by game version and seasonal updates. Check the Hero Trial menu in-game for your server's current schedule.

Squad Strategy

You typically need to run trials with the same troop type as the featured hero. The squad you bring decides whether you clear the highest stages.

Hero Type Matching

Featured Hero TypeBring
Tank Hero TrialMono-Tank squad. Use your strongest Tank composition (Kimberly + Murphy + Williams + Marshall + Stetmann/Scarlett)
Aircraft Hero TrialMono-Aircraft squad. DVA + Morrison + supporting Aircraft heroes (or Murphy Exception in front)
Missile Hero TrialMono-Missile squad. Tesla + Fiona + Venom + supporting Missile heroes

The trial PvE enemies are typically the opposing troop type to the featured hero (so a Tank Hero Trial features Missile enemies — which Tanks beat).

Maximising Daily Attempts

  • Run every available daily attempt — partial completion still earns rewards but full completion compounds
  • Clear the highest stage you can survive — even one clear of the highest stage beats multiple clears of lower stages
  • Save healing speedups if necessary — Hero Trial is one of the few PvE events worth burning healing on
  • Coordinate with alliance for difficult stages — some servers allow assist requests for stuck stages

Rewards

Each Hero Trial run delivers a tiered reward chest. Higher stages = better chests.

Reward TypeWhy It Matters
Named hero shardsThe headline reward. Targeted shards for the featured UR hero. Direct progression toward 5★
Skill MedalsUniversal currency for hero skill upgrades. Always useful
Hero EXPDirect hero levelling currency. Save for VS Day 4 if not capped
GemsSmall daily contribution to your VIP push or gem economy
SpeedupsModest amounts. Bank for VS Day 5

A typical week of disciplined Hero Trial play yields:

  • 50-100 named hero shards (split across the rotated heroes)
  • 5,000-10,000 Skill Medals
  • 100,000+ Hero EXP
  • Modest gem and speedup income

Cross-Server Hero Trial

A periodic upgrade to the daily Hero Trial.

How It Differs

  • Cross-server pairings — your server is matched with another for a competitive Hero Trial week
  • Rankings produce additional rewards — top performers earn substantially more
  • Higher-difficulty stages unlock — new content beyond standard Hero Trial
  • Limited-time event — usually 3-5 days per cycle

Cross-Server Strategy

  1. Push your highest stage early — top players lock in ranking points fast
  2. Coordinate with alliance — assists become more valuable for top-25 ranks
  3. Use your strongest squad — Cross-Server Hero Trial is harder than standard
  4. Don't skip daily attempts — every attempt scores ranking points

Common Hero Trial Mistakes

  1. Skipping the daily run — the most expensive miss. Daily shards add up
  2. Running trials with mismatched squad type — significantly weaker performance vs type-matched squad
  3. Wasting attempts on low stages — clear the highest stage you can survive
  4. Burning healing speedups outside Hero Trial — this is one of the few events where heal-and-retry pays off
  5. Ignoring Cross-Server Hero Trial — better rewards than the daily, fewer players engage with it
  6. Not levelling the squad you're using — bringing under-levelled heroes to higher stages wastes attempts
  7. Forgetting to claim chest rewards — some servers require a manual claim. Check after each cycle

Hero Trial vs. Other Daily PvE

Last War has multiple daily PvE events. Hero Trial fits in like this:

EventCadenceBest For
Hero TrialDaily, rotating heroTargeted hero shards + skill medals
Hero Trial (Cross-Server)Periodic, 3-5 daysBigger rewards, ranking competition
Rampage BossesDaily, rotating bossSkill medals, gear materials
Wanted BossWeekly scheduleDiamonds, Hero XP, Ability Medals, Hero Shards
Sky PredatorPeriodic alliance eventHonor Points, alliance currency
Marshal's GuardEvery 2-3 daysHonor Points, alliance rewards

Hero Trial sits at the highest priority for daily PvE because it produces named hero shards. No other daily event produces equivalent targeted hero progression.
